# 设置卡片视觉规范 · research-dispatch（v2.3.0）

> 基准：`dsh-claude-style` + `@deepseek-ai/dsh-client-ui-primitives`（离线沙箱自动回退 1.5px 描边 SVG 与语义 HTML）。
> 宿主设计语言由 `--dsw-alias-*` 令牌定义，本文件只做**转写与落位**：
> 把同一套温润极简视觉语言用到「科研派工 · 全流程阵容与拓扑」工作台上，零原生 `<select>`、零 Unicode 伪图标、零刺眼渐变与大面积扩散阴影，所有数值启用 `tabular-nums`。

## 0. 页面结构与全流程编排原则

页面只摆**真实参与运行**的配置项，按科研闭环从上到下排成五大分区：

```
工作流项目 → 文献调研 → 想法发散 → 多票评审 → 前置查重
```

- **工作流项目**：指定当前科研项目文件夹路径（留空则自动探测；宿主挂载 `uiWorkspace.pickDirectory` 或 `directoryPicker` 时内联展示原生「浏览…」按钮，误填 `.dsh/profiles/*` 时自动净化提示）。点击底部「保存」后，面板各环节阵容会自动通过 `syncPanelLineupToSeats` 写穿同步进该项目配置文件（`dispatch/seats.json` 的 `lineup`），桌面端与外部命令行共享同一份生效阵容，且绝不改动用户手写的底层座位属性。
- **文献调研（S0）**：通过 DSH 风格定制下拉组件 `ExecPicker`（宿主持有 `Prim.Menu` 时自动走 `portal: true` 弹出菜单，离线环境走无障碍 `role="listbox"`）选择由谁检索论文并整理结构化文献卡片（`默认（按配置）` 或五大 CLI 工具联动模型）。
- **想法发散（S2）**：选择由谁产出候选研究想法，并内联配置**「单轮默认条数」**（`1–50` 等宽数字输入，默认 `10`）与**「历史死胡同过滤」**无障碍拨杆 `UiSwitch`（`Prim.Switch` / `role="switch"`，带清晰中文开启/关闭状态说明）。
- **多票评审（S4）**：多评审员独立打分的阵容与票数。支持五大 CLI 工具自由增删，允许**同一工具排多票对比不同模型**（如两票 `codex` 分别选不同模型），也允许跨工具使用同一模型（系统如实记录票源，不强行毁票）；留空（0 票）则按项目配置文件里的默认阵容运行。
- **前置查重（S4.5）**：选择由谁在投入正式长训前对入围想法执行单单隔离的外部查新。
- **五合一清晰工具列表（移除 `api` 干扰项）**：前端统一展示五大真实 CLI 工具——`codex · Codex CLI`、`claude · Claude Code`、`dsh · DeepSeek Harness`、`agy · Antigravity`、`kimi · Kimi Code`（本机未检测到命令时柔和标注 `（未检测到命令）`；仅当历史旧配置当前值残留 `api` 或 `gemini` 时才渲染兼容项供用户平滑切走）。
- **零死锁模型选择器（`ModelPicker`）**：打开弹层时始终常驻顶部搜索兼自定义模型输入框（即使探测到的候选模型数为 `0` 或 `≤4` 也常驻）；未输入过滤词时首项常驻 `默认（使用该工具自身默认模型）` 以便随时一键切回默认；输入任意非空模型名且与现有项不重名时，列表直接提供可点击或回车选中的 `使用自定义模型：<名称>`。

分区标题**就是环节名本身**（`工作流项目`、`文献调研`、`想法发散`、`多票评审`、`前置查重`），不加 `①` / `②` 编号前缀。

## 1. 五条不可违反的规则

1. **只用宿主 alias 令牌**（`--dsw-alias-*` / `--dsw-font-family`）。不写死 `#d97757` 这类色值 ——
   主题切换（浅色 / 深色 / 不同品牌皮肤）时本页自动跟随。
2. **行不做盒子**。分区靠 `0.5px` 发丝线 + 留白，不嵌套内层卡片、不叠阴影（浮层菜单除外）。
3. **4px 间距节奏**。所有区块与行内的 `padding` / `gap` / `margin` 取 `4px` 的整数倍（`4 / 8 / 12 / 16 / 20 / 24`）。
4. **单一强调色，占比 <10%**。只允许出现在：主按钮填充、焦点环、模型选中态、`已覆盖` 徽标。
   危险操作（删除）使用 danger 令牌，且仅在悬停时显色。
5. **状态成体系**：常态 / 悬停 / 焦点 / 禁用 / 空态 / 加载共用同一套节奏，
   过渡只动颜色与边框/阴影，时长 `120ms`，并尊重 `prefers-reduced-motion`。

## 2. 令牌落位

| 用途 | 令牌 | 备注 |
|---|---|---|
| 正文 / 标签 | `--dsw-alias-label-primary` | 13px / 500 |
| 说明 / 次要 | `--dsw-alias-label-tertiary` | 12.5px / 400 |
| 当前值回显 | `--dsw-alias-label-secondary` + 等宽字体 | 11.5px，`code` |
| 控件描边 | `--dsw-alias-border-l1` | 1px |
| 分区与行分隔线 | `--dsw-alias-border-l2` | 0.5px |
| 悬停浮层 | `--dsw-alias-bg-layer-2` | 按钮与弹层选项悬停 |
| 强调色 | `--dsw-alias-brand-primary` | 焦点环 / 主按钮回退 / 选中标记 |
| 主按钮 | `--dsw-alias-button-primary-fill` / `-hover` + `--dsw-alias-label-primary-foreground` | 带品牌色与白色字回退 |
| 告警与危险态 | `--dsw-alias-state-warn-primary` / `--dsw-alias-state-error-primary` | 删除按钮仅悬停显色 |

## 3. 版式

```
页面标题        18px / 600
一句导语        12.5px / 三级灰
─────────────── 0.5px 发丝线（24px 上外边距 + 20px 上内边距）
区块标题        15px / 600
区块说明        12.5px / 三级灰（4px 上外边距）
行              左右两栏，12px 上下内边距，行间 0.5px 分隔线
  左：标签 13px/500 + 副行 12px/三级灰（当前值用等宽 code）
  右：控件簇，右对齐，间距 8px
───────────────
页脚            状态文字（左）+ 放弃 / 保存按钮（右）
```

两栏网格：`minmax(0, 1fr) auto`，列间距 `16px`。容器宽度 `≤560px`（优先 `@container`，辅以 `@media` 回退）时折成单栏，控件簇占满整行。

## 4. 控件规格

| 控件 | 高度 | 圆角 | 描边 | 悬停 | 焦点 | 禁用 |
|---|---|---|---|---|---|---|
| 下拉 / 输入 / 模型按钮 | 30px | 8px | 1px `border-l1` | 描边升至 `border-l3` | 描边转强调色 + 3px 16% 焦点环 | 不透明度 .55 |
| 次要按钮 | 30px | 8px | 1px `border-l1` | 底浮 `bg-layer-2`、文字转一级 | 同上焦点环 | 不透明度 .45 |
| 主按钮 | 30px | 8px | 无描边 | `button-primary-hover` | 同上焦点环 | 不透明度 .45 |
| 删除按钮 | 28px | 8px | 透明 | 文字转 danger + danger 9% 底 | 同上焦点环 | 不透明度 .45 |
| 加票按钮 | 34px | 8px | 1px 虚线 `border-l1` | 描边转强调色、文字转一级 | 同上焦点环 | 不透明度 .45 |

## 5. 空态与异常态（严禁整页空白）

| 情形 | 形态 |
|---|---|
| 连接中 | `12px` 圆角、`bg-layer-1` 底说明块：`正在连接设置服务…（首次打开会慢一点）` |
| 暂无可编辑项 | 同一说明块：`设置服务连上了，但本页暂时没有可编辑项…`（不误报为连接故障） |
| 连不上设置服务 | 同一说明块：`连不上设置服务（原因：…），这一页只能看说明、不能修改…`；下方骨架仍在且所有交互控件全部禁用 |
| 当前未单独排票 | 行内虚线提示框：说明将按配置文件里的默认评审阵容运行，可点 `+ 加一票` 自由添加 |
| 0 候选模型弹层 | 常驻输入框 + `默认（使用该工具自身默认模型）`，输入文本即可创建 `使用自定义模型：<名称>` |
| 保存成功 / 失败 | 页脚状态位（成功绿字 / 失败红字），不弹全局 toast |

## 7. 文案规则（面向所有用户）

面板正文不暴露内部脚本后缀、配置键名或底层字段名（如 `.sh`、`.json`、`default_backends`、`model_override`、`scoutCommand`、`divergeUseDeadEnds` 等）。所有说明只回答「这一项管什么、改了会怎样」。

统一术语表：

| 概念 | 使用词汇 | 禁用词汇 |
|---|---|---|
| 一次独立评审 | 票 | 座位、slot |
| 执行某环节的一方 | 工具 / 评审员 | 执行者、backend、seat |
| 被评审的对象 | 想法 | 工单、idea、brief |
| 检索整理文献卡片 | 文献调研 | scout |
| 生成候选想法 | 想法发散 | diverge、发散器 |
| 入围后检索撞车风险 | 前置查重 | novelty |
| 面板连接的宿主接口 | 设置服务 | 网关、命名空间、RPC |
| 项目级持久化配置 | 项目的配置文件 | `dispatch/seats.json`、`seats[i]` |

## 8. 信息完整性清单

修改 `lib/client.js` 时逐条核对以下要素，缺一不可：

- 页面标题（`科研派工 · 全流程阵容`）与导语（说明按闭环搭配各环节工具与模型，保存后自动同步至所选项目的配置文件中，桌面端与命令行共享生效）
- 三种连接状态提示（连接中 / 暂无可编辑项 / 连不上设置服务 + 具体原因）
- `工作流项目` 分区：项目文件夹输入框与当前路径回显
- `文献调研` 分区：工具下拉（`默认（按配置）` + 五大 CLI 工具）与联动模型选择弹层
- `想法发散` 分区：工具下拉、联动模型选择弹层、`单轮默认条数`（`1–50`，默认 `10`）、`历史死胡同过滤`（常规挂载已证伪方向 vs 纯空白零历史锚定模式）
- `多票评审` 分区：0 票空态提示、每票序号、五大 CLI 工具下拉（`codex` / `claude` / `dsh` / `agy` / `kimi`）、模型选择弹层、「当前」回显、删除按钮、`+ 加一票` 按钮
- `前置查重` 分区：工具下拉与联动模型选择弹层
- `ModelPicker` 弹层：常驻顶部搜索/自定义输入框、首项常驻恢复默认选项、输入未收录模型名时渲染 `使用自定义模型：<名称>` 并支持回车即选
- `其他设置`（仅当存在无专用控件的新增字段时渲染，含字段说明与 `已修改` 徽标）
- 页脚：保存状态提示、`放弃`、`保存`
