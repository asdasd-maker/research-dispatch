# 设置卡片视觉规范 · research-dispatch

> 基准：`dsh-claude-style`。宿主设计语言由 alias 令牌定义，本文件只做**转写与落位**：
> 把同一套视觉语言用到「科研派工」设置页上，不引入独立色板或第三种卡片样式。
> 改这张卡先读这里；改品牌色去改宿主主题令牌，不要在组件里硬编码颜色。

## 0. 页面结构与全自由编排原则

页面只摆**真实参与运行**的配置项，按主次从上到下排成两节：

```
评审 → 发散
```

- **评审**：多模型独立评审的阵容与票数。支持 `codex` / `claude` / `dsh` / `gemini` / `api` 自由增删，允许**同一工具排多票对比不同模型**（如两票 `codex` 分别选 `gpt-5` 与 `o3`），也允许跨工具使用同一模型（系统如实记录票源，不强行毁票）；留空（0 票）则按项目配置文件里的默认阵容运行。
- **发散**：生成候选想法时调用的工具与模型。v2.0.0 已解锁全部有效执行者（`默认（按配置）` / `codex` / `claude` / `dsh` / `gemini` / `api` / `kimi`），切换左侧执行者即自动联动右侧模型选择器。

节的标题**就是环节名本身**（`评审`、`发散`），不加 `①` / `②` 编号，也不加「每轮都用 / 按需才用」前缀；使用时机与作用域放在说明行与底部提示中（DSH 面板配置仅在当前 DSH 宿主内生效，不跨宿主污染项目配置文件）。

## 1. 五条不可违反的规则

1. **只用宿主 alias 令牌**（`--dsw-alias-*` / `--dsw-font-family`）。不写死 `#d97757` 这类色值 ——
   主题切换（浅色 / 深色 / 不同品牌皮肤）时本页自动跟随。
2. **行不做盒子**。分区靠 `0.5px` 发丝线 + 留白，不嵌套内层卡片、不叠阴影（浮层菜单除外）。
3. **4px 间距节奏**。所有区块与行内的 `padding` / `gap` / `margin` 取 `4px` 的整数倍（`4 / 8 / 12 / 16 / 20 / 24`）。
4. **单一强调色，占比 <10%**。只允许出现在：主按钮填充、焦点环、模型选中态、`已覆盖` 徽标。
   危险操作（删除）使用 danger 令牌，且仅在悬停时显色。
5. **状态成体系**：常态 / 悬停 / 焦点 / 禁用 / 空态 / 加载共用同一套节奏，
   过渡只动颜色与边框/阴影，时长 `120ms`，并尊重 `prefers-reduced-motion`。

## 2. 令牌落位

| 用途 | 令牌 | 备注 |
|---|---|---|
| 正文 / 标签 | `--dsw-alias-label-primary` | 13px / 500 |
| 说明 / 次要 | `--dsw-alias-label-tertiary` | 12.5px / 400 |
| 当前值回显 | `--dsw-alias-label-secondary` + 等宽字体 | 11.5px，`code` |
| 控件描边 | `--dsw-alias-border-l1` | 1px |
| 分区与行分隔线 | `--dsw-alias-border-l2` | 0.5px |
| 悬停浮层 | `--dsw-alias-bg-layer-2` | 按钮与弹层选项悬停 |
| 强调色 | `--dsw-alias-brand-primary` | 焦点环 / 主按钮回退 / 选中标记 |
| 主按钮 | `--dsw-alias-button-primary-fill` / `-hover` | 带品牌色回退 |
| 危险态 | `--dsw-alias-state-danger-fg` | 删除按钮仅悬停显色 |

## 3. 版式

```
页面标题        18px / 600
一句导语        12.5px / 三级灰
─────────────── 0.5px 发丝线（24px 上外边距 + 20px 上内边距）
区块标题        15px / 600
区块说明        12.5px / 三级灰（4px 上外边距）
行              左右两栏，12px 上下内边距，行间 0.5px 分隔线
  左：标签 13px/500 + 副行 12px/三级灰（当前值用等宽 code）
  右：控件簇，右对齐，间距 8px
───────────────
页脚            状态文字（左）+ 放弃 / 保存按钮（右）
```

两栏网格：`minmax(0, 1fr) auto`，列间距 `16px`。容器宽度 `≤560px`（优先 `@container`，辅以 `@media` 回退）时折成单栏，控件簇占满整行。

## 4. 控件规格

| 控件 | 高度 | 圆角 | 描边 | 悬停 | 焦点 | 禁用 |
|---|---|---|---|---|---|---|
| 下拉 / 输入 / 模型按钮 | 30px | 8px | 1px `border-l1` | 描边升至 `border-l3` | 描边转强调色 + 3px 16% 焦点环 | 不透明度 .55 |
| 次要按钮 | 30px | 8px | 1px `border-l1` | 底浮 `bg-layer-2`、文字转一级 | 同上焦点环 | 不透明度 .45 |
| 主按钮 | 30px | 8px | 无描边 | `button-primary-hover` | 同上焦点环 | 不透明度 .45 |
| 删除按钮 | 28px | 8px | 透明 | 文字转 danger + danger 9% 底 | 同上焦点环 | 不透明度 .45 |
| 加票按钮 | 34px | 8px | 1px 虚线 `border-l1` | 描边转强调色、文字转一级 | 同上焦点环 | 不透明度 .45 |

## 5. 空态与异常态（严禁整页空白）

| 情形 | 形态 |
|---|---|
| 连接中 | `12px` 圆角、`bg-layer-1` 底说明块：`正在连接设置服务…（首次打开会慢一点）` |
| 暂无可编辑项 | 同一说明块：`设置服务连上了，但本页暂时没有可编辑项…`（不误报为连接故障） |
| 连不上设置服务 | 同一说明块：`连不上设置服务（原因：…），这一页只能看说明、不能修改…`；下方骨架仍在且所有交互控件全部禁用 |
| 当前未单独排票 | 行内虚线提示框：说明将按配置文件里的默认评审阵容运行，可点 `+ 加一票` 自由添加 |
| 未探测到评审员清单 | 行内虚线提示框：说明票仍可保存，实际由系统按默认安排 |
| 保存成功 / 失败 | 页脚状态位（成功绿字 / 失败红字），不弹全局 toast |

## 7. 文案规则（面向所有用户）

面板正文不暴露内部文件路径、脚本后缀、配置键名或底层模型代号（如 `.sh`、`.json`、`default_backends`、`model_override`、`kimi-k3` 等）。所有说明只回答「这一项管什么、改了会怎样」。

统一术语表：

| 概念 | 使用词汇 | 禁用词汇 |
|---|---|---|
| 一次独立评审 | 票 | 座位、slot |
| 执行评审的一方 | 评审员 / 工具 | 执行者、backend、seat |
| 被评审的对象 | 想法 | 工单、idea、brief |
| 生成候选想法 | 发散 | diverge、发散器 |
| 面板连接的宿主接口 | 设置服务 | 网关、命名空间、RPC |
| 深层静态配置 | 配置文件 | `dispatch/seats.json`、`seats[i]` |
| 默认调度方 | 系统 | 主会话、编排器、subagent |

## 8. 信息完整性清单

修改 `lib/client.js` 时逐条核对以下要素，缺一不可：

- 页面标题（`科研派工 · 评审与发散`）与导语（说明自由编排工具与模型、如实记录票源，含「改完保存即可，下一轮生效」）
- 三种连接状态提示（连接中 / 暂无可编辑项 / 连不上设置服务 + 具体原因）
- `评审` 节标题与说明（讲清票与几位评审员的对应关系、支持同一工具排多票、以及不排票时按配置文件默认阵容运行）
- 评审票列表：0 票空态提示、每票序号、有效评审员下拉（`codex` / `claude` / `dsh` / `gemini` / `api`）、模型选择弹层、「当前」回显、删除按钮（支持删空最后一票恢复默认阵容，断连态下禁用）
- 无可用评审员清单时的兜底说明与 `+ 加一票` 按钮（支持无限追加同工具多票）
- 进阶提示（说明本页配置作用域为当前桌面端，跨工具共享阵容可在项目配置文件中指定）
- `发散` 节标题与说明、全执行者下拉（`默认（按配置）` / `codex` / `claude` / `dsh` / `gemini` / `api` / `kimi`）、联动模型选择弹层与「当前」回显
- `高级项`（仅当存在无专用控件的新增字段时渲染，含字段说明与 `已覆盖` 徽标）
- 页脚：保存状态提示、`放弃`、`保存`
