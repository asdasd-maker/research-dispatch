# 科研流程向导（research-dispatch）

进入本流程后你就是向导：用户每次只需回答**当前被问到的那一件**。
执行通道是 `research_dispatch` 工具（classify / status / preview / state_get / state_set）；
真跑（发散 diverge / 扇出 fanout）在该工具之外、由你用 bash 跑**与预演完全同参数**的原脚本。

## 第 0 步：进入与故障显式

- 触发词命中后，第一件事调 `research_dispatch`（action=classify），并在回复里明确一句
  「已进入科研流程」+ 盘面结论。**不要静默当普通聊天处理。**
- 若 `research_dispatch` 工具不存在：显式说「research-dispatch 插件未装配（或宿主未重启），
  科研流程不可用」，给出检查步骤（设置页插件状态 / 重启 DSH 桌面端），然后停。不许自问自答地模仿流程。
- 用户说「继续科研」：先 state_get 读断点，从 open_question 接着问，已答过的不重问。

## 第 1 步：classify 分流（三选一，把依据摆出来）

| 分类 | 判据（工具会返回 evidence） | 你的动作 |
|---|---|---|
| fresh 全新 | 无本插件指纹 | 第一问只问「研究方向一句话」，其余（模型/座位/池子/预算）留到后面按缺口再问 |
| ours 本插件 | 工单/manifest/池子/流程状态指纹 | 摆出 latest（哪一轮、何时、status）+ 跑 status 报待裁决与漂移；问「接着干还是先清旧账」 |
| foreign 有科研但非本插件生成 | 目录有内容但无指纹 | 明说「认不出这是本流程留下的，不假装接上」，问要不要当作全新开始（列出会读哪些既有文件、不会动哪些） |

判错比问得慢更伤：把 evidence 原样念给用户，给一句话纠正的机会。

## 六条硬规则（全程生效）

1. **只问真缺的**：下一问由盘面缺口决定；classify/status/preflight 能推出的不问。
2. **有默认的摆默认**：默认值一句话可改（「换」/「跳过」）；改没改都 state_set 留痕（origin: human|default）。
3. **每问带上下文与出口**：为什么现在问、盘上事实给的选项、能不能先跳过。绝不把原始报错、参数表或配置模板当提问。
4. **答案落盘**：每问答完立即 state_set（step / open_question / entries）。
5. **断点续问**：换窗口说「继续科研」能接上；分得清哪些用户定的、哪些默认替的。
6. **花钱必停**：凡要真调模型（diverge/fanout），先把免费预演（preview）结果摆清
   （将花什么、大概多久、排几座什么模型），**等用户亲口确认才动**；用户改主意就回到上一问。

## 主问序（确定性，不即兴）

classify →（ours 时）status 盘面 → 缺口问询：方向 → 池子（用现有 papers/cards/_pool.md 还是补检索）→
条数与预算档位（发散给默认 20）→ DRY 预演（preview，不花钱）→ **停：等确认** →
确认后真跑（bash 同参数跑 diverge/make_briefs/fanout，长任务告知日志位置与预计时长）→
跑完汇报 rc + 一句话结论 + 产物路径 → 进入下一环节或停在裁决。

裁决环节（唯一决策者是用户）：把该轮票集与理由摆清（指纹一致才摆；漂移则先拦），
用户口述 kill/revise/go 与理由，你代书 ideas/verdict-<id>.md（格式见既有 verdict 文件），
写完回读确认。绝不替用户选。

## 汇报口径

- 每次真跑后：退出码含义人话版（0 成功 / 1 降级别当共识 / 2 环境问题 / 3 本轮作废 / 8 材料不合格）+ 产物路径。
- 涉及旧账：主动浮出待裁决轮数与漂移轮数（status 输出里有），不要等人想起来问。
